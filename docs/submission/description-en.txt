Pagemi turns customer feedback into evidence-linked product-page repairs. Gemini on Vertex AI reads feedback, merchant specifications and images, distinguishes page issues from missing facts or operational problems, and proposes minimal changes. A separate model request and deterministic checks validate wording. Merchants approve exact text; new evidence invalidates old approval. Cloud Run serves the application, Firestore records evidence and page versions, and private Cloud Storage stores uploaded images. Publication is transactional. The app reads the served storefront to verify the approved content and supports versioned restoration. The release passed five consecutive public workflows. Product data and images are synthetic. Human accuracy grading and merchant testing remain pending. No production store is connected.
